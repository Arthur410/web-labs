# Лабораторные по веб-технологиям

| Работа | Что внутри | Запуск |
| --- | --- | --- |
| [1](lab1) | Тетрис на TypeScript и Canvas | `npm ci`, затем `npm run dev` из `lab1` |
| [2](lab2) | Книги на Express и Pug | `npm ci`, затем `node app.js` из `lab2`. Адрес `http://127.0.0.1:1337` |
| [3](lab3) | Соцсеть на Express, Pug и WebSocket | API и страницы на `https://localhost:1338`, локальный чат на порту 9999 |
| [4](lab4/frontend) | Angular-клиент соцсети | Запустить работу 3, затем `npm ci` и `npm start` из `lab4/frontend` |
| [5](lab5) | Симулятор биржи на NestJS, Socket.IO и React | `npm ci` и `npm start` отдельно из `lab5/back` и `lab5/front`. Сервер на порту 5000 |

### Соцсеть

В каталоге `lab3` выполните `npm ci --ignore-scripts`, чтобы пропустить установку нативного модуля устаревшей сборки. Для локального HTTPS укажите пути к собственному ключу и сертификату для `localhost` через `LAB3_TLS_KEY` и `LAB3_TLS_CERT`. Затем выполните `npm run serve` и откройте `https://localhost:1338`. Для Angular браузер также должен доверять этому сертификату. Каталог `lab3/.tls` исключён из Git.

Новый аккаунт можно создать в Angular. Для входа под пользователями из учебного набора задайте локальный пароль через `LAB3_DEMO_PASSWORD` перед запуском. Имена и новости демонстрационных профилей доступны для чтения. Изменения профиля требуют учётных данных его владельца. После перезагрузки Angular вход нужно повторить.

### Биржевой симулятор

Начать можно с регистрации в React. Альтернативный вход в учебные профили включается переменной `LAB5_DEMO_PASSWORD` на сервере. Капитал и удаление доступны только владельцу профиля. Любой вошедший брокер может запускать общий учебный раунд и выбирать акции для него. После отключения сокета вход нужно повторить.

### Проверки и данные

Для работы 1 используйте `npm run build`. В работе 2 сценарий редактирования запускается командой `node --test app.test.js`, в работе 3 тесты API запускаются через `npm test`. Angular, NestJS и React собираются командой `npm run build` из своих каталогов.

Работы 2–5 рассчитаны на локальный запуск. Изменения в рабочих данных и сессии сбрасываются после перезапуска серверов.
